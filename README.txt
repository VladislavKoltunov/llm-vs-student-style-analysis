# LLM vs Student Text Style Analysis

Corpus-based analysis of linguistic differences between
LLM-generated and student-written essays.

## Dataset

Source:
https://huggingface.co/datasets/knarasi1/student_and_llm_essays

## Methods

- Corpus statistics
- Lexical diversity
- Mann–Whitney U test
- Cliff's delta
- POS-tagging with spaCy
- Function word analysis
- Visualization

## Results

The analysis shows differences in:

- lexical characteristics
- grammatical patterns
- function word usage

## Tools

Python, pandas, spaCy, scipy, matplotlib
